## Сборка проекта
Проект собирается с помощью *webpack* 

Команда ***npm run build*** \
Результат сборки папка **dist**


## Структура проекта
Весь проект находится в папке **src**. \
Внутри **src** есть следующие папки:
* **assets** — шрифты и картинки (в соответствующих папках **fonts** и **images**)
* **scripts** — код проекта логически разбитый по папкам (каждая папка отвечает за свою страницу или компонент), а так же файлы с константами и вспомогающими функциями

## Сторонние библиотеки
* redom 
* ymaps для Яндекс карт

## Запуск тестов
1. npx cypress open
2. В открывшемся окне выбрать пункт "end-to-end testing", далее выбрать браузер Chrome
3. Всего есть 2 файла с e2e тестами:
    * тест на login
    * тест на функционал счетов

**Login** тест проверяет 4 возможных сценария:
1. авторизация прошла успешно
2. пароль не верный (выходит ошибка с соответствующим сообщением)
3. логин не верный (пользователь не найден)
4. пароль или логин слишком короткие (поле подсвечивается красным)

**Accounts** тесты проверяют следующий функционал:
1. новый счёт успешно создаётся
2. перевод со счёта (не пустого) на счёт
3. перевод средств с нового счёта, т.к. счёт создаётся пустым, то выходит ошибка о недостаточном количестве средств для перевода
