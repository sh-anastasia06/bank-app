# Bank App - Веб-приложение для банковских операций

Веб-приложение для управления банковскими счетами, созданное с использованием чистого JavaScript, HTML и CSS.

## 🎯 Функциональность

- 👤 **Аутентификация пользователей** - Вход в систему
- 💰 **Просмотр баланса** - Текущий баланс счетов
- 📊 **История операций** - Просмотр транзакций
- 🔄 **Переводы денег** - Перевод между счетами
- 💸 **Снятие средств** - Операции снятия наличных
- 📱 **Адаптивный дизайн** - Работа на всех устройствах

## 🛠 Технологии

- **HTML5** - Семантическая разметка
- **CSS3** - Стилизация и анимации
- **JavaScript (ES6+)** - Вся логика приложения
- **Local Storage** - Хранение данных пользователя
